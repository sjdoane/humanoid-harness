## Search and selection receipt

- Questions: composition from scale; embodied ICL; state-aware oracle priors; visual reward diagnosis versus reward/policy prompting; compatible existing motion trackers.
- Routes: supplied GEN page/video; arXiv primary pages; cited official project repositories; targeted reward/robot-feedback and humanoid-tracking searches; existing local source registry and source manifests.
- Selection rule for this advisory note: a source must change a design choice, challenge the main claim, or inform an immediately feasible adapter/reference decision.
- Coverage: positive evidence for ICL and scale, positive evidence for explicit oracle/reward adaptation, evaluator limitations and prior composition methods.
- Missing: direct matched humanoid policy-ICL versus two-knob experiment; complete artifact reproduction; formal systematic search/screening; private/future model access.
- No absence claim is inferred from those gaps. No candidate-table row is promoted to an included scientific source by this note.
